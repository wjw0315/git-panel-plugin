Git 面板把 IDE 风格的 Git 工作流带进 Paseo。它以 workspace 标签页打开，顶部的仓库切换器还能识别工作区内部的嵌套仓库与 worktree。

面板包含分支与标签、带车道图的提交历史与逐提交文件差异，以及支持暂存、取消暂存、放弃、提交与 Amend 的变更列表。它可以 fetch、fast-forward pull、push、发布分支、创建标签、revert、reset 当前分支，并管理贮藏。文件浏览器可预览文本、Markdown 与图片；桌面端用 CodeMirror 6 阅读与编辑（行号、语法高亮、搜索、快捷键），停止输入 1.5 秒自动保存，保存前校验磁盘版本，文件被外部改动时保留草稿而不覆盖。移动端自动降级为纯文本编辑器。

每个智能体输入框上方有一个小标记，显示当前仓库与分支。工作区干净时为绿色，有未提交变更时为橙色，点击可打开面板。Paseo 只在智能体存在后才画这条栏，因此工作区标题栏另有一个 Git 按钮：首次发起会话、还没有智能体时也能打开面板。新建 workspace 页面既没有标题栏也没有智能体，那里显示工作区的起点分支，以及 worktree 会新建的分支。

使用前提是 daemon 机器上有 Git CLI，并开启插件的全局开关。Git 命令以 argv 数组执行，不经过 shell，工作目录固定为仓库根，并带超时与输出上限。插件自身不发起网络请求；只有点击 fetch、pull、push 时才会访问远端，凭据由 Git 处理。文件访问限制在工作区内，`.git` 不可浏览，编辑仅限少量文本类型并采用原子替换。

已知限制：未包含提交信息生成，因为 Paseo 没有向插件暴露 metadata generation；历史筛选只覆盖提交信息与哈希前缀，不含作者、日期与历史路径；差异视图提供统一/对照布局与全文展开，但不支持按折叠块逐段展开或图片缩放。
