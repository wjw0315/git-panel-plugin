## 1. 初始需求

用户原话：

> 给 Paseo 复刻一个一模一样的插件 `@xbzbing/dsh-git-panel@1.11.0`。

原插件是 DSH Web GUI 的 IDE 风格 Git 面板，把分支列表、提交历史图、未提交变更的提交与 amend、diff 对照、文件浏览集中到一个常驻标签页，并在输入框左侧放一个 zsh 风格 `<仓库名> (<分支>)` 标记。

Paseo 没有 DSH 的 typert / Cordis 宿主，需要按 Paseo 插件契约重写，而不是移植原 bundle。

## 2. 原插件功能基线

| 模块 | 原版能力 |
|---|---|
| Git 总览 | 分支/标签列表、提交历史图、提交详情、逐文件差异、消息/哈希搜索、路径历史搜索、作者/日期筛选 |
| 变更记录 | 逐文件/批量暂存、放弃、commit、amend、stash、增删行统计、平铺/树形视图 |
| 常用操作 | 切换分支、增删标签、revert、reset，破坏性操作二次确认 |
| 差异查看 | 统一/对照/变更前/变更后、语法高亮、词级强调、按需展开、图片缩放 |
| 文件浏览 | 目录树、代码/Markdown/HTML/图片预览、配置/文档类文件编辑 |
| 多仓库 | worktree、子目录独立仓库自动识别与切换 |
| 输入框标记 | `<仓库名> (<分支>)`，绿色已同步、橙色有变更，点击打开面板 |
| AI 提交信息 | 跟随当前会话模型生成（依赖 DSH 宿主 LLM 服务） |
| 多语言 | 8 种语言 |

## 3. 交付物与使用

安装：

```bash
paseo plugin install /Users/jiaweiwu/paseo-plugins/git-panel
paseo plugin ls          # git-panel  running  yes
```

入口：

- **⌘K / Ctrl+K** → `Open Git panel`（workspace 目录）
- **⌘K** → `Open Git panel for this agent`（agent 的 `cwd`）
- 标签栏 **+** → **Git**
- 点击输入框上方 `● <仓库> (<分支>)` 标记（agent 级面板）

设置：**⌘K** → `Configure Git panel`，或 Settings → Plugins → git-panel。

## 4. Paseo 插件契约映射

| 层 | Paseo 形态 |
|---|---|
| 宿主 | daemon 子进程，可使用 Node API，无沙箱 |
| 通信 | `defineRpc` + zod 契约；客户端 `useRpc` |
| UI | React Native primitives；`addWorkspacePanel` / `addAgentPanel` |
| 输入框标记 | `addComposerPill`（每个 agent 的 composer track） |
| 设置 | `defineSettings` + `useSettings` |
| 面板参数 | `useWorkspace(workspaceId, selector)` / `useAgent(agentId, selector)` |
| 命令入口 | `addCommandCenterItem`（workspace / agent 上下文） |

服务端 RPC：

- `git.repos` / `git.snapshot` / `git.refs` / `git.history` / `git.show`
- `git.diff` / `git.dir-list` / `git.file-content` / `git.file-write`
- `git.stash-list` / `git.last-message` / `git.action`

客户端结构：

```text
client/panel.tsx     面板壳、仓库切换、标签页、字面路径
client/overview.tsx  分支/提交历史/提交详情
client/changes.tsx   变更列表、提交框、stash
client/files.tsx     目录树与文件预览/编辑
client/diff-view.tsx 统一/对照 diff
client/pill.tsx      输入框 <仓库> (<分支>) 标记
client/settings.tsx  设置页
server/*             git 命令、解析、快照、动作
shared/git.ts        RPC 契约、zod 数据模型、设置定义
```

## 5. 已实现能力

- **多仓库**：workspace 根仓库 + 子目录嵌套仓库（深度 3、上限 50），可切换。
- **总览**：本地/远程分支、标签、车道图提交历史、提交详情、逐文件 diff、消息/哈希前缀搜索、加载更多。
- **变更**：已暂存/已修改/未跟踪分组，逐文件与批量暂存/取消/放弃，平铺/树形，逐文件 `+/-`，commit、amend、stash（应用/弹出/删除）。
- **同步**：fetch、fast-forward pull、push、publish。
- **其他 Git**：切换/新建分支、创建标签、revert、reset（soft/mixed/hard，二次确认）。
- **Diff**：统一/对照、行号、词法着色、全文上下文展开。
- **文件**：懒加载目录树、忽略项半透明、文本/Markdown/图片预览、允许类型文件编辑（sha256 版本校验 + 原子替换）。
- **输入框标记**：绿色=干净、橙色=有变更、灰色=未知；有变更时带 `*`；点击打开 agent 级面板。
- **设置**：输入框标记开关、默认 diff 视图、变更列表默认视图、自动刷新间隔、是否允许编辑、文件浏览是否跟随仓库。
- **适配**：中英双语、窄屏单栏、主题色。

## 6. 与原版的差异

| 项目 | 差异 |
|---|---|
| AI 生成提交信息 | **未实现**。Paseo 协议没有向插件暴露 metadata generation（只有 `checkout_commit_request`，没有“只生成消息”的 RPC）。 |
| 提交历史图 | 简化的车道图（竖线 + 节点 + 分支连接），无原版弯折线与完整车道配色。 |
| 历史筛选 | 只支持提交信息/哈希前缀；无作者、日期、历史路径子串筛选。 |
| Diff | 无逐折叠块展开、词级 diff、图片缩放/拖拽/全屏。 |
| 文件预览 | 文本着色、Markdown、图片；HTML 不渲染。 |
| 多语言 | 中/英；原版 8 种。 |
| 输入框标记 | 颜色体现在圆点上（文字颜色由 Paseo 控制），标签带 `*`。 |

## 7. 复刻过程中踩到的 Paseo 插件契约坑

1. **RPC name 大小写**：只允许小写字母、数字、点、连字符、下划线。`git.dirList` 这类大写会让整个插件加载失败（`Invalid plugin RPC method`，`plugin ls` 直接 failed）。
2. **client bundle 不随 `plugin reload` 更新到已连接 App**：server 端 reload 后 client 还是旧 bundle；改 UI 后需在 Paseo 里按 **⌘R**。
3. **zod 输出校验在客户端**：`snapshot.lastChangeAt` 用 `stat.mtimeMs` 浮点而 schema 是 `z.number().int()`，客户端整条 RPC 校验失败，面板永远“加载中”；时间戳必须 `Math.floor`。
4. **composer pill**：`client.paseo.agents.list({ subscribe: {}, signal })` 订阅 agent，再 `addComposerPill({ id, workspaceId, agentId, button })`；返回 `{ update, remove }`。自定义 icon 可直接返回 RN `View` 彩色圆点。
5. **设置**：`defineSettings({ id, scope: "host", version, schema })`；server `registerSettings`；客户端 `useSettings`。入口外读设置可用 `client.rpc(settingsRpc(id).read, {})`，但要自己 `schema.safeParse`。
6. **目录型插件刷新 manifest**：`paseo plugin remove` + `install`；`remove` 不删源码目录。
