# Spec Delta

## Purpose

定义 Git 面板「文件」页的文本编辑与只读预览行为：桌面端提供带行号与语法高亮的编辑器、Proma 式自动保存与手动保存、冲突保护、Markdown 源码/预览切换，并在移动端或缺少 DOM 的宿主上降级为纯文本编辑，保证功能不退化。

## ADDED Requirements

### Requirement: 桌面端只读预览

文件页在桌面宿主中打开文本文件时，必须（MUST）以只读代码视图展示内容，而不是纯文本块。

#### Scenario: 打开代码文件

- **WHEN** 用户在桌面端点选一个文本文件
- **THEN** 预览区显示带行号的只读代码视图，并按文件扩展名进行语法着色
- **AND** 长行可横向滚动或按设置自动换行，不截断内容

#### Scenario: 打开大文件

- **WHEN** 文件超过大文件阈值（当前为 2 MiB 或渲染行数上限）
- **THEN** 预览区降级为纯文本展示并提示已降级
- **AND** 面板不因渲染该文件而卡死或超时

#### Scenario: 打开 Markdown 文件

- **WHEN** 用户打开 `.md` / `.markdown` 文件
- **THEN** 默认展示 Markdown 渲染结果
- **AND** 工具栏提供「预览 / 源码」切换，源码态使用只读代码视图

### Requirement: 桌面端文本编辑

在允许编辑的设置开启、且文件类型属于可编辑白名单时，用户必须（MUST）能用代码编辑器修改文本。

#### Scenario: 进入编辑态

- **WHEN** 用户点击已有文件的「编辑」按钮
- **THEN** 预览区切换为可编辑的代码编辑器，光标就位且保留原有滚动位置
- **AND** 编辑器提供行号、语法着色、括号匹配、缩进与撤销/重做

#### Scenario: 编辑中的常用快捷键

- **WHEN** 编辑器获得焦点
- **THEN** `⌘S` / `Ctrl+S` 与 `⌘Enter` / `Ctrl+Enter` 触发保存，`Esc` 退出编辑态
- **AND** 快捷键不会触发宿主浏览器的默认保存或提交行为

#### Scenario: 退出编辑态

- **WHEN** 用户按 `Esc` 或点击取消
- **THEN** 编辑器恢复为只读视图并丢弃本次未保存草稿
- **AND** 若存在未保存修改，取消操作需避免无提示丢失

### Requirement: 保存与自动保存

文件保存必须（MUST）同时支持手动保存与防抖自动保存，并且在磁盘内容被外部修改时不覆盖他人改动。

#### Scenario: 手动保存

- **WHEN** 用户按 `⌘S` 或点击保存
- **THEN** 内容写入磁盘，编辑器保持焦点，状态提示变为「已保存」
- **AND** 未保存标记清除

#### Scenario: 自动保存

- **WHEN** 自动保存在设置中开启且用户停止输入 1.5 秒
- **THEN** 系统自动保存当前草稿，并显示保存中/已保存状态
- **AND** 连续输入不会产生重叠的保存请求

#### Scenario: 磁盘冲突

- **WHEN** 保存时磁盘文件的哈希与编辑基线不一致
- **THEN** 保存被拒绝，提示文件已在磁盘上被修改
- **AND** 草稿保留在编辑器中，用户可重新加载或复制后继续

#### Scenario: 自动保存关闭

- **WHEN** 用户在设置中关闭自动保存
- **THEN** 只有显式保存（快捷键或按钮）才写盘
- **AND** 未保存修改在标签上以修改标记呈现

#### Scenario: 编辑未启用

- **WHEN** 设置中关闭文件编辑，或文件类型不在可编辑白名单内
- **THEN** 编辑器保持只读，不显示编辑入口，写接口拒绝该请求

### Requirement: 移动端与无 DOM 宿主降级

在不具备 DOM 的宿主（移动端原生或检测失败）上，文件页必须（MUST）继续可用。

#### Scenario: 移动端编辑

- **WHEN** 用户在移动端打开可编辑文件并进入编辑态
- **THEN** 使用纯文本编辑框完成编辑与保存，行为与当前版本一致
- **AND** 不出现空白区域、模块加载错误或面板崩溃

#### Scenario: 只读预览降级

- **WHEN** 宿主无法挂载代码编辑器
- **THEN** 以纯文本形式展示文件内容并保留行号
- **AND** 面板其余功能保持可用

### Requirement: 编辑器设置

文件编辑器的新增行为必须（MUST）可通过设置页控制，并与现有设置一起持久化。

#### Scenario: 设置项生效

- **WHEN** 用户切换「自动保存」或「编辑态语法高亮」开关
- **THEN** 下一次打开文件时按新设置生效，无需重载面板
- **AND** 设置变更与中英文案同步展示

#### Scenario: 设置默认值

- **WHEN** 用户从未修改过编辑器设置
- **THEN** 自动保存开启、编辑态语法高亮开启，且与现有默认设置一并返回
