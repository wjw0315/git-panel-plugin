# 01 分支页搜索框（含键盘与清空）

Status: done (2026-11-21)
Blocked by: —

来源：2026-11-21 用户截图 —— 分支一多只能滚，页面上没有过滤入口。

## What to build

分支页顶部加一个搜索输入框，输入即过滤分支列表：

1. 按**分支名子串**匹配，大小写不敏感；匹配范围包含远端前缀，所以输入 `origin` 会列出该远端下的全部分支。
2. 输入即过滤，无需回车；无匹配时显示一行 `没有匹配的分支`，而不是空白。
3. 过滤词在切到别的页签再切回来时**保留**；清空后恢复完整列表。
4. 键盘：`⌘/Ctrl + F` 聚焦搜索框，`Esc` 清空并让输入框失焦；输入框右侧有清空按钮（有内容时才出现）。
5. 纯前端过滤，不改 worker、不发请求；分支清单仍由现有的分支列表请求提供。

不要做：按提交信息搜分支、模糊/拼写纠错、跨页签全局搜索。

## Acceptance criteria

- [ ] 过滤函数可单测：`proto` 命中 `prototype/*`，`ORIGIN` 命中 `origin/*`，空串返回全部，无命中返回空数组。
- [ ] 面板断言：输入后列表项数量变少；清空后恢复；无匹配时出现 `没有匹配的分支`。
- [ ] 面板断言：切到别的页签再回来，输入框里仍是上次的词、列表仍是过滤后的结果。
- [ ] 键盘：`⌘F` 后输入框获得焦点；`Esc` 清空且失焦。
- [ ] 分支列表请求次数不因输入而变化（用请求记录断言：输入前后请求数相同）。
- [ ] `tsc -p .` 无错，`orca plugin test` 全绿，`orca plugin check` 场景 issues 与 warnings 全空。
