# 02 分支页本地/远端分组与计数

Status: done (2026-11-21)
Blocked by: #01

来源：同一份截图。分支平铺成一列后，「哪些是本地、哪些是远端」只能靠名字猜；过滤时也需要知道剩了多少。

## What to build

把分支列表分成两组渲染：

1. 组头：`本地 N` 与 `远端 M`，N/M 是**当前过滤结果**里的数量（不是总数）；空组不渲染组头。
2. 每个分支一行，保持现有行结构：名字一行、`远端 / 当前` 标签一行、右侧 `切换` 与删除图标。
3. **当前分支固定在第一行**（无论它在哪一组），并带 `当前` 标签、不显示切换与删除。
4. 组内排序：本地按名字；远端按名字（`origin/main` 这类完整名）。
5. 与 #01 的搜索组合：先分组再按过滤词筛，计数取筛后结果。

不要做：按远端再折一层、拖拽排序、分支置顶自定义。

## Acceptance criteria

- [ ] 面板断言：未过滤时出现 `本地 N` / `远端 M`，且 N、M 与实际条数一致。
- [ ] 面板断言：输入过滤词后组头计数同步变小；某个组筛空后该组头消失。
- [ ] 面板断言：当前分支始终是第一行，且不带 `切换` / 删除按钮。
- [ ] 单测：分组函数对「只有本地」「只有远端」「混合」三种输入都返回稳定的顺序与计数。
- [ ] `tsc -p .` 无错，`orca plugin test` 全绿，`orca plugin check` 场景 issues 与 warnings 全空。
