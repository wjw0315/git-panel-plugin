# 02: 冲突解决清单组件

**What to build:** 一个新的纯展示组件，把「进行中 + 冲突文件清单 + 每文件三种解决动作 + 继续/中止」画出来，并把点击翻译成回调。语义标签必须按进行中态翻转：合并态显示「保留当前分支 / 保留来源分支」，变基态显示「保留目标分支 / 保留我的提交」。组件不发 RPC，数据与回调由宿主传入（与 `UpdateBranchDialog` 既有分层一致）。

**Blocked by:** 01（回调语义依赖 resolve/continue 契约）

**Status:** ready-for-agent

- [ ] 新组件渲染冲突文件逐行清单（monospace 文件名，可点击回调看该文件 diff）
- [ ] 每行三个动作：`标记已解决`（无 strategy）、`保留当前分支/目标分支`（`ours`）、`保留来源分支/我的提交`（`theirs`）
- [ ] 标签随 `branchState` 翻转，变基态不得出现「当前分支/来源分支」字样
- [ ] 冲突数 > 0 时继续按钮禁用并显示剩余数量；清空后可用并回调
- [ ] 继续按钮文案随进行中态切换（继续合并 / 继续变基）
- [ ] 中止按钮保留既有文案与确认形态
- [ ] pending 时所有动作禁用，不重复触发
- [ ] 所有按钮带悬停 hint（既有 hint 覆盖测试把关）
- [ ] 双语文案（en + zh）全部补齐
- [ ] 渲染测试：文件行渲染、三种动作回传正确 `(path, strategy)`、变基态标签翻转、继续禁用/可用切换、中止回调、pending 禁用
- [ ] typecheck 与现有测试回归通过
