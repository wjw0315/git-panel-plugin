git-panel-plugin

这一版对应已实现的行为

  • 顶部七个页签：提交 / 更改 / 基准 / 历史 / 贮藏 / 分支 / 更多；标签带计数，一次只显示一页。
  • 提交页里就是这次要提交的已暂存文件；点更改页的 +，文件从「更改」搬到「提交」。
  • 更改页右上角切 树形 / 平铺：树形是单行目录（箭头 + 名字 + 数量 + 目录级动作），只显示文件名。
  • 基准页可选任意远端/本地分支；两个动作「获取并合并」「仅合并本地基准」；fetch 失败降级合并；失败就地红字 + 原始输出。
  • 分支页每行两行文字（名字 / 标签），右侧只有一个「切换」和删除图标，不会把按钮顶出边界。
