这一版改了什么

  • 没有页签。历史 / 贮藏 / 分支 / 基准都是可折叠卡，不离开工作区，也没有「返回」。
  • 提交卡里就是这次提交的内容。点某行的 +，它从「更改」搬到「提交」，反向点 − 搬回去。
  • 提交是两段式。主按钮 + ▾ 在卡内展开「提交并推送 / 同步 / 强推」，每种都带不可用原因。
  • 基准常驻。收起态就写着「领先 3」，展开能看到是哪三条，并可一键拉取。
  • 13 个远端动作收进顶部 ···，不再占一整页。
  • 冲突永远最先出现，占住顶部，提交按钮同时禁用并写明「有冲突」。

试着点这些

  • 点文件行的 + / −，看它在两张卡之间移动。
  • 点「提交」右边的 ▾，再点 Esc 收起。
  • 点「基准」卡头，展开后点「拉取基准分支」。
  • 顶部切到「冲突」，看解决行和完成合并的启用时机。
